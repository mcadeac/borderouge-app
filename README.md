# Borderouge — app tablette KFC Toulouse Borderouge

Site : https://mcadeac.github.io/borderouge-app/

- `index.html` : accueil · `formation.html` : CLO, QCM, suivi · `smep.html` : SMEP
- Les données (noms, résultats, commentaires) et les corrigés des QCM restent dans les Google Sheets
  et leurs scripts : ce dépôt n'en contient **aucun**.
- `config.js` : adresses `/exec` des scripts des Sheets. Sans le code restaurant, ils refusent toute lecture ou écriture.
